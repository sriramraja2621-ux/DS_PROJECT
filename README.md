# Smart Traffic Light Controller

## Overview
The **Smart Traffic Light Controller** is a Java-based simulation that dynamically manages traffic signals 
at a four-way intersection. It prioritizes lanes based on:
- The number of waiting vehicles
- The presence of emergency vehicles

This project demonstrates how a simple algorithmic system can improve traffic efficiency and reduce waiting time.

---

## System Requirements
- **Operating System:** Windows 10 / 11, macOS, or Linux
- **Java Version:** JDK 17 or higher
- **IDE (optional):** Visual Studio Code / IntelliJ IDEA / Eclipse
- **Terminal or Command Prompt access**

---

1. Download or clone this project folder named `SmartTrafficLightController`.
2. Open the folder in your preferred IDE or navigate to it via terminal.
